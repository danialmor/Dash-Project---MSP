# دسترسی Claude به گیت‌هاب: چه کاری با کدام مجوز

مخزن: `danialmor/Dash-Project---MSP` · اتصال: «github» در Claude (آدرس `api.githubcopilot.com/mcp`)

## وضعیت فعلی (بررسی‌شده)
| کار | وضعیت |
|---|---|
| خواندن مخزن | کار می‌کند |
| ساخت یا ویرایش فایل عادی (کد، مستندات، تست) | کار می‌کند |
| ساخت مخزن جدید | رد شد (۴۰۳) |
| ساخت یا ویرایش فایل داخل `.github/workflows` | رد شد (۴۰۳) |

محدودیت‌های جدا از مجوز: فایل بزرگ `msp-bi/index.html` (حدود ۶۰۰ کیلوبایت) از این اتصال نمی‌گذرد؛ آن را باید خودتان با Upload files جایگزین کنید.

## اگر می‌خواهید Actionها را هم خودکار بریزم
فایل‌های workflow مجوز جداگانه‌ای می‌خواهند (در گیت‌هاب: `workflow`).

1. در Claude: Customize ← Connectors ← github ← **Disconnect**، بعد **Connect**.
2. صفحه‌ی گیت‌هاب را با دقت بخوانید. مجوزی مثل «Update GitHub Action workflows» را رد نکنید و **Authorize** بزنید.
3. گفتگو را تازه کنید و بنویسید «چک کن».
4. اگر دوباره ۴۰۳ شد: به `github.com/settings/applications` ← Authorized OAuth Apps بروید و برنامه‌ی مربوط به این اتصال را باز کنید. اگر مجوز workflow در فهرست نیست، این اتصال آن را نمی‌دهد (از این اتصال مطمئن نیستم که بتواند).

## اگر مجوز workflow باز نشد
فقط این دو فایل را خودتان بسازید (Add file ← Create new file با مسیر کامل). متن هر دو در پیام‌های همان گفتگو آمده؛ هر وقت لازم شد «متن workflow را بده» بنویسید:
- `.github/workflows/unpack.yml` (بازکردن خودکار zip)
- `.github/workflows/deploy.yml` (استقرار روی سرور؛ تا خرید سرور لازم نیست)

بقیه‌ی فایل‌ها را من می‌ریزم.

## قاعده‌ی «چک کن»
وقتی می‌نویسید «چک کن»، فقط آزمون نوشتن می‌زنم و در یک خط می‌گویم درست شد یا نه.
